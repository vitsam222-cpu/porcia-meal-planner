# Порция

Интерактивный планировщик питания с ориентиром около 1600 ккал в день.

**Онлайн:** https://vitsam222-cpu.github.io/porcia-meal-planner/

- 80 блюд с отдельными иллюстрациями: 20 завтраков, 20 обедов, 20 ужинов, 20 перекусов.
- Бытовые порции без взвешивания, короткие рецепты, пересчёт на 1–3 порции.
- План на семь дней, сумма калорий и белка, избранное, поиск и фильтры.
- Список покупок с суммированием продуктов, отметками и выгрузкой в TXT.
- Экспорт и импорт плана в JSON для переноса между устройствами; печать недели.
- Без регистрации, аналитики и серверного хранения. Сохранение в localStorage текущего браузера.

## Локальный запуск

```sh
python3 -m http.server 8765
```

Открой http://localhost:8765. Сборка и зависимости не нужны. GitHub Pages публикует ветку `main`, папку `/`.

## Данные

`data.js` содержит продукты и рецепты; `app.js` — интерфейс и локальное состояние; `style.css` — адаптивные стили. Калории и белок рассчитаны по средним значениям продуктов, округлены. Не предназначены для точного медицинского расчёта. 1600 ккал — ориентир этого меню, а не рекомендация всем пользователям. Личные параметры человека в исходники не включены.

Изображения сгенерированы и иллюстрируют идеи блюд; состав и фактическую порцию смотри в рецепте. Шрифты Lora и Manrope распространяются по SIL Open Font License; лицензии находятся в `assets/`.

Бытовые меры круп, хлопьев и макарон всегда относятся к сухому продукту до варки; стакан 250 мл. Фильтр «Проще всего» выделяет простые домашние блюда.

Все ингредиенты в рецептах и списке покупок показаны бытовыми мерами. Калории ориентировочные, поскольку объёмные меры и размеры продуктов различаются.
