# Порция

Интерактивный планировщик питания с ориентиром около 1600 ккал в день.

**Онлайн:** https://vitsam222-cpu.github.io/porcia-meal-planner/

- 320 блюд с отдельными иллюстрациями: 80 завтраков, 80 обедов, 80 ужинов, 80 перекусов.
- Бытовые порции без взвешивания, короткие рецепты, пересчёт на 1, 2 взрослые порции или всю семью.
- План на семь дней, сумма калорий и белка, избранное, поиск и фильтры.
- Список покупок с суммированием продуктов, отметками и выгрузкой в TXT.
- Экспорт и импорт плана в JSON для переноса между устройствами; печать недели.
- Без регистрации, аналитики и серверного хранения. Сохранение в localStorage текущего браузера.

## Локальный запуск

```sh
python3 -m http.server 8765
```

Открой http://localhost:8765. Сборка и зависимости не нужны. GitHub Pages публикует ветку `main`, папку `/`.

## Данные

`data.js` содержит продукты и рецепты; `app.js` — интерфейс и локальное состояние; `style.css` — адаптивные стили. Калории и белок рассчитаны по средним значениям продуктов, округлены. Не предназначены для точного медицинского расчёта. 1600 ккал — ориентир этого меню, а не рекомендация всем пользователям. Личные параметры человека в исходники не включены.

Изображения сгенерированы и иллюстрируют идеи блюд; состав и фактическую порцию смотри в рецепте. Шрифты Lora и Manrope распространяются по SIL Open Font License; лицензии находятся в `assets/`.

Бытовые меры круп, хлопьев и макарон всегда относятся к сухому продукту до варки; стакан 250 мл. Фильтр «Проще всего» выделяет простые домашние блюда.

Все ингредиенты в рецептах и списке покупок показаны бытовыми мерами. Калории ориентировочные, поскольку объёмные меры и размеры продуктов различаются.

Подбор «Что есть дома» сортирует блюда по доле отмеченных ингредиентов и показывает недостающее. Режим «Всё есть дома» оставляет полные совпадения; наличие не означает достаточное количество. Выбор продуктов сохраняется локально и входит в экспорт плана.

Фильтр способа готовки («Одна сковорода», «Без духовки», «Без готовки», «Минимум посуды») сочетается с поиском и существующими фильтрами. Метки заданы в данных рецептов. «Минимум посуды» означает одну основную ёмкость, без учёта ножа и доски.

Личные исключения (молочные продукты, бобовые, капуста, лук, орехи и арахис) действуют на каталог и случайный подбор. Уже выбранное меню не изменяется автоматически. Фильтр проверяет перечисленные ингредиенты, а не состав упаковок и следы аллергенов. В рецептах есть подсказки о переносимости с источниками NIDDK; отсутствие симптомов не гарантируется.

Режимы взрослых порций 1300/1600 ккал (по умолчанию 1600), пересчёт ингредиентов, калорий, белка, покупок и печати. 1300 — низкокалорийный вариант, не индивидуальная рекомендация. Детские порции к этим режимам не относятся.
80 новых семейных блюд, фильтр «Семейные». В рецепте: 1, 2 или вся семья (2 взрослых и 3 детей). Семейная заготовка = две взрослые порции выбранного режима + запас на 2½ обычные порции для детей; это ориентир для готовки, подача детям по аппетиту.
