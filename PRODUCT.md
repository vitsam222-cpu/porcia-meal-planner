## Platform
web
## Stack
Static HTML/CSS/JavaScript proposed for GitHub Pages. No account or server required; browser-local persistence approved by user.
## Users
Russian-speaking user choosing meals and cooking without weighing every ingredient.
## Product Purpose
Turn the existing 1600 kcal menu into an interactive daily and weekly planner. Sixty recipes per meal, four meals per day.
## Capabilities and Constraints
Household portions without weighing; selectable recipes; local persistence; GitHub upload and a working online link requested. Daily calories approximate. No personal health profile in public source.
## Brand Commitments
Preserve the approved menu's green editorial identity, food imagery, readable recipe cards.
## Evidence on Hand
Existing PDF menus and generated food contact sheet in work/pdf. No photographs of the actual prepared servings.

User preference: familiar simple home cooking; cereal cup measures always refer to dry cereal before cooking, using a 250 ml cup.

Latest preference: all ingredient quantities in cards, recipes and shopping lists use household measures without weighing. No gram-mode control. Sixty familiar home dishes per category, each with a recipe.

Latest scope: 240 home recipes and local generated photos; pantry ingredient selection with match ranking, missing products and strict mode (approved by user); combinable cooking-method filters; optional product exclusions and evidence-linked digestive-tolerance notes. Pantry and exclusions are local preferences, included in JSON transfer, backward compatible with existing version-1 plans. Avoid promises of symptom-free digestion or unsupported food-combining rules.
